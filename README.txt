DIPUU'S BIRTHDAY SURPRISE WEBSITE ❤️

ADD HER PHOTO
1. Put her chosen photo in this folder beside index.html.
2. Rename the photo to dipuu.jpg.
3. Open index.html in Chrome to preview.

OPTIONAL MUSIC
Add a song file named birthday-song.mp3 in this folder. The floating music button will play/pause it after a tap. Use a song you have permission to use.

INTERACTIVE FEATURES
- Full-screen 3D gift-box unboxing intro.
- Starfield, floating hearts, glowing orbits and 3D heart.
- Interactive 3D Polaroid photo card.
- Personalized Nepali-English love letter.
- Tap-to-blow birthday cake candles with a confetti burst.
- Make-a-wish animation.
- Tap-to-open keepsake envelope and secret note.
- Optional user-controlled music toggle.
- Responsive mobile layout.
